📋 Demo Instructions

This is the customer-site.html demo page, acting as a third-party site that embeds the platform's widget via the one-line script tag.

  • Make sure the platform server is running: npm run dev
  • Create a tenant + widget and grab the widget ID from the API response.
  • Replace YOUR_WIDGET_ID_HERE in the <script> tag below (or directly in this file).
  • Reload this page — the widget will pop up automatically, or click Get Early Access.
<!-- Drop this one-liner anywhere on your site -->
<script
  src="http://localhost:3000/widget.js"
  data-widget-id="cms4z49j20001gn9gkx1v98az"
  async defer></script>
